# aa-linux wallpapers

Eight Redline wallpapers built from the aa-linux mark and the theme palette,
one for each desktop theme color.

| File | Notes |
| --- | --- |
| `aa-linux-redline.svg` / `.png` | Debian-red field, cropped A, carbon badge |
| `aa-linux-cobalt.svg` / `.png` | Cobalt colorway of Redline |
| `aa-linux-mint.svg` / `.png` | Mint colorway of Redline |
| `aa-linux-violet.svg` / `.png` | Violet colorway of Redline |
| `aa-linux-ember.svg` / `.png` | Ember colorway of Redline |
| `aa-linux-ice.svg` / `.png` | Ice colorway of Redline |
| `aa-linux-sand.svg` / `.png` | Sand colorway of Redline |
| `aa-linux-blush.svg` / `.png` | Blush colorway of Redline |

The SVGs are the editable sources. PNG exports are 2560 × 1440. The 1280 × 720
JPEG copies used by the bundled desktop are in
`openbox-desktop/config/wallpaper/`.

The wallpapers are deliberately text-free. The Tux artwork is inlined from
`../assets/logo-mark.svg`; keep the artwork attribution in
`THIRD_PARTY_NOTICES.md` with any redistribution.

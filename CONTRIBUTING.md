# Contributing

Contributions are welcome. Please open an issue before substantial protocol or
transport changes so compatibility and legal provenance can be discussed.

- Keep changes focused and document observable protocol behavior.
- Do not submit private keys, APKs, decompiled proprietary code, captures with
  credentials, vehicle identifiers, or copyrighted test media.
- Add or update tests for framing, protobuf, transport, and error handling changes.
- Run `python -m compileall aa-linux` and `make test` before submitting a change.
- Use the existing GPL-3.0-or-later headers and preserve third-party attribution.
